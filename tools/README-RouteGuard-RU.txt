KADR — восстановление маршрута локальной сети при AmneziaVPN на Windows 10/11

1. Распакуйте ZIP.
2. ПКМ на INSTALL-RouteGuard.cmd → Запуск от имени администратора.
3. Подтвердите UAC. Задача запустится и будет автоматически работать при запуске Windows.

Действие: каждые 5 секунд удаляется ТОЛЬКО ошибочный маршрут /32 к собственному физическому Wi-Fi/Ethernet IPv4 через интерфейс с именем AmneziaVPN.
Если меняется IP Wi-Fi, новое значение определяется автоматически.

НЕ меняет KillSwitch, настройки VPN, DNS и firewall. Если KillSwitch блокирует LAN, маршрут сам по себе не снимет блокировку. Поэтому включение KillSwitch может вновь сделать KADR недоступным.

Удаление: ПКМ на UNINSTALL-RouteGuard.cmd → Запуск от имени администратора.

Проверка:
PowerShell: Get-ScheduledTask -TaskName 'KADR Amnezia LAN Route Guard'
Подключение к собственному IP: Test-NetConnection 192.168.68.60 -Port 8791

100% работа любых сетей не гарантируется; нужен доступный Wi-Fi/LAN и разрешение VPN на локальную связь или независимый HTTPS relay.
