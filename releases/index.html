31 AUG 2026 · PUBLIC SITE 0.1

KADR finally has a front door.

Until today, getting KADR involved knowing where the repository lived, which build was the right build, and generally behaving like a person who enjoys ZIP archaeology. That is over.

KADR now has a public home with one download page, a proper description of the app, documentation, and this release journal. The private code stays private; the public repository becomes the place where actual public builds and their history live.

Also: Russian and English now share the same site. Civilization advances.

У КАДР наконец появилась входная дверь.

До сегодняшнего дня скачивание КАДР местами требовало знать, где лежит репозиторий, какая сборка правильная и вообще любить археологию по ZIP-файлам. Всё, хватит.

Теперь у КАДР есть публичный дом: одна страница загрузки, нормальное описание приложения, документация и этот журнал обновлений. Приватный код остаётся приватным; публичный репозиторий становится местом, где живут реальные публичные сборки и их история.

А ещё русский и английский теперь живут на одном сайте. Прогресс человечества продолжается.
