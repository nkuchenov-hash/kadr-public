31 AUG 2026 · PUBLIC SITE 0.1

KADR finally has a front door

KADR now starts from one clear public place: the current build, the documentation and the release history all live together.

KADR has a public home with one download page, a proper description of the app, documentation, and this release journal. The private code stays private; the public repository becomes the place where actual public builds and their history live.

Russian and English now share the same site. Civilization advances.

У КАДР наконец появилась входная дверь

Теперь КАДР начинается с одного понятного публичного места: актуальная сборка, документация и история обновлений живут вместе.

У КАДР появился публичный дом: одна страница загрузки, нормальное описание приложения, документация и этот журнал обновлений. Приватный код остаётся приватным; публичный репозиторий становится местом, где живут реальные публичные сборки и их история.

Русский и английский теперь живут на одном сайте. Прогресс человечества продолжается.
