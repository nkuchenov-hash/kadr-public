Capture on Windows

Скриншоты в Windows

KADR is designed around region capture. Start capture with the configured hotkey or tray action, select the required area, and the editor controls appear around the selection. The intended workflow is capture → optional annotation → Copy / Save.

КАДР построен вокруг захвата области. Запустите скриншот назначенной горячей клавишей или через трей, выделите нужную область, после чего вокруг выделения появляются инструменты. Основной сценарий: захват → при необходимости разметка → Copy / Save.

Editing tools

Инструменты редактирования

The editor is intended for fast annotations: text, arrows, lines, rectangles, ellipses, numbered markers, blur, pixelation, pen and highlighter. Editing stays attached to the captured area for a fast, focused workflow.

Редактор предназначен для быстрых пометок: текст, стрелки, линии, прямоугольники, эллипсы, нумерованные маркеры, размытие, пикселизация, перо и маркер. Редактирование остаётся привязанным к самому снимку и сохраняет быстрый сфокусированный рабочий процесс.

Long screenshots — KADR scrolls for you

Длинные скриншоты — КАДР прокручивает сам

1. Press Alt+Shift+S (configurable in Settings → Hotkeys). Select the scrollable content of a webpage, list, document or chat. Avoid fixed browser headers and sidebars when possible.

1. Нажми Alt+Shift+S (меняется в Настройки → Горячие клавиши) и рамкой выдели прокручиваемое содержимое сайта, списка, документа или чата. По возможности не включай в рамку неподвижные шапки и боковые панели.

2. In the panel under the red frame, choose ↓ Down to capture a website or long list, or ↑ Up to capture older chat messages. Press Start. KADR now scrolls the selected application a small amount, captures the next section, checks alignment and repeats. You do not need to scroll or press Add.

2. В панели под красной рамкой выбери ↓ Вниз для сайта или списка, либо ↑ Вверх для старых сообщений чата. Нажми «Старт». КАДР будет сам понемногу прокручивать приложение, снимать новые участки и проверять их совмещение. Прокручивать вручную и нажимать «Добавить» не нужно.

3. At the desired ending point, press Stop. Scrolling stops and KADR saves one tall PNG automatically on disk and in History. The panel then shows the actual path and Open file / Folder / Close buttons. No second save confirmation is required.

3. Дойдя до нужного места, нажми «Стоп». Прокрутка прекратится, а КАДР сам сохранит один длинный PNG на диск и в историю. Панель покажет путь к файлу и кнопки «Открыть / Папка / Закрыть». Дополнительно подтверждать сохранение не нужно.

4. If the page stops moving, the maximum length is reached, or a continuous image cannot be assembled reliably, KADR stops by itself. Press Save to keep the captured section. Cancel discards only an unsaved session.

4. Если страница перестала прокручиваться, достигнута максимальная длина или программа не может надёжно продолжить захват, КАДР остановится сам. Нажми «Сохранить», чтобы оставить уже снятое. «Отмена» закрывает несохранённый захват.

Output format: a single long PNG (PDF export is not implemented). Different applications handle mouse-wheel input differently; the Windows build and automated tests passed, but capture on a specific website or in Yandex Telemost still requires a practical check.
Формат результата — один длинный PNG (экспорт в PDF пока не реализован). Разные приложения обрабатывают прокрутку по-разному. Windows-сборка и автоматические тесты прошли, но захват конкретного сайта или чата Яндекс Телемоста ещё нужно проверить на практике.

Android Companion

KADR Companion watches the Android screenshot flow and queues files for delivery to your paired PC. If the PC is temporarily unavailable, queued items stay pending and retry automatically later.

KADR Companion отслеживает поток скриншотов Android и ставит файлы в очередь на отправку подключённому ПК. Если компьютер временно недоступен, элементы остаются в очереди и автоматически повторяют отправку позже.

Pairing phone and PC

Подключение телефона к ПК

Open the mobile-device connection area in KADR on Windows and pair Companion with that PC. Pairing establishes the device identity and transfer credentials used by the receiver. Keep both devices on the same network for the fastest direct path.

Откройте раздел подключения мобильного устройства в КАДР на Windows и привяжите Companion к этому ПК. Подключение создаёт идентификатор устройства и данные авторизации для передачи. Для самого быстрого прямого пути лучше держать оба устройства в одной сети.

How transfer works

Как работает передача

Direct LAN transfer is the primary path. Companion sends the file to the authenticated KADR receiver on the paired computer. If the PC address changes, Companion can resolve the endpoint again. A relay path extends compatible transfers when direct delivery is temporarily unavailable.

Основной путь — прямая передача по локальной сети. Companion отправляет файл в авторизованный приёмник КАДР на подключённом компьютере. Если адрес ПК изменился, Companion может заново определить endpoint. Relay расширяет возможности совместимой передачи, когда прямой путь временно недоступен.

For large videos in the current preview, use direct LAN. Relay currently focuses on smaller compatible transfers.
Для больших видео в текущей preview-версии используйте прямую передачу по LAN. Relay сейчас ориентирован на более компактные совместимые передачи.

History and continued editing

История и продолжение редактирования

KADR history keeps captures discoverable, sortable and reopenable so saved annotations can be continued later. This area is still being actively refined in the preview build.

История КАДР сохраняет снимки доступными, сортируемыми и повторно открываемыми, чтобы работу с разметкой можно было продолжить позже. В preview-версии этот раздел ещё активно дорабатывается.

Troubleshooting

Решение проблем

Phone screenshot is not appearing on PC

Скриншот с телефона не появляется на ПК

Check that KADR is running on Windows, Companion still shows the intended paired computer, and both devices have network access. If direct transfer cannot reach the PC, leave the item queued rather than deleting the local source immediately.

Проверьте, что КАДР запущен в Windows, Companion всё ещё показывает нужный подключённый компьютер и оба устройства имеют доступ к сети. Если прямая передача не может достучаться до ПК, лучше оставить элемент в очереди, а не удалять исходный файл сразу.

Download stops or says interrupted

Загрузка прерывается

Use the Download page on this site. The buttons are designed to point to the current public release assets. If a release is temporarily being published, try the Releases page to verify which build is current.

Используйте страницу Download на этом сайте. Кнопки должны вести на файлы текущего публичного релиза. Если релиз прямо сейчас публикуется, откройте раздел Обновления и проверьте, какая сборка является актуальной.
