These docs describe the public preview workflow. The goal is deliberately simple: install KADR on Windows, capture quickly, and optionally pair Android Companion for phone-to-PC transfers.

Документация

БЫСТРЫЙ СТАРТ
МЕНЬШЕ МЕНЮ

Эта документация описывает текущую preview-версию. Сценарий специально простой: установить КАДР в Windows, быстро делать снимки и при желании подключить Android Companion для передачи с телефона на ПК.

Use the newest files from the Download page. KADR Public is the public distribution point; old random installers should not be treated as canonical builds.
Используйте самые свежие файлы со страницы Download. KADR Public — публичная точка распространения; случайные старые установщики не считаются каноническими сборками.

Capture on Windows

Скриншоты в Windows

KADR is designed around region capture. Start capture with the configured hotkey or tray action, select the required area, and the editor controls appear around the selection. The intended workflow is capture → optional annotation → Copy / Save.

КАДР построен вокруг захвата области. Запустите скриншот назначенной горячей клавишей или через трей, выделите нужную область, после чего вокруг выделения появляются инструменты. Основной сценарий: захват → при необходимости разметка → Copy / Save.

Editing tools

Инструменты редактирования

The editor is intended for fast annotations: text, arrows, lines, rectangles, ellipses, numbered markers, blur, pixelation, pen and highlighter. Editing should remain attached to the captured area instead of becoming a separate heavyweight graphics application.

Редактор предназначен для быстрых пометок: текст, стрелки, линии, прямоугольники, эллипсы, нумерованные маркеры, размытие, пикселизация, перо и маркер. Редактирование остаётся привязанным к самому снимку, а не превращается в отдельный тяжёлый графический редактор.

Android Companion

KADR Companion watches the Android screenshot flow and queues files for delivery to your paired PC. If the PC is temporarily unavailable, queued items can remain pending and retry later instead of requiring you to manually resend every screenshot.

KADR Companion отслеживает поток скриншотов Android и ставит файлы в очередь на отправку подключённому ПК. Если компьютер временно недоступен, элементы могут остаться в очереди и повторить отправку позже — не нужно вручную пересылать каждый снимок заново.

Pairing phone and PC

Подключение телефона к ПК

Open the mobile-device connection area in KADR on Windows and pair Companion with that PC. Pairing establishes the device identity and transfer credentials used by the receiver. Keep both devices on the same network for the fastest direct path.

Откройте раздел подключения мобильного устройства в КАДР на Windows и привяжите Companion к этому ПК. Подключение создаёт идентификатор устройства и данные авторизации для передачи. Для самого быстрого прямого пути лучше держать оба устройства в одной сети.

How transfer works

Как работает передача

Direct LAN transfer is the primary path. Companion sends the file to the authenticated KADR receiver on the paired computer. If the PC address changes, Companion can resolve the endpoint again. A relay path is available as a fallback for compatible transfers when direct delivery is not possible.

Основной путь — прямая передача по локальной сети. Companion отправляет файл в авторизованный приёмник КАДР на подключённом компьютере. Если адрес ПК изменился, Companion может заново определить endpoint. Для совместимых передач существует резервный relay-путь, когда напрямую доставить файл не получается.

Large video transfers are best treated as direct-LAN functionality in the current preview. The relay path is not yet the canonical route for large MP4 recordings.
Большие видео в текущей preview-версии лучше считать функцией прямой передачи по LAN. Relay пока не является каноническим путём для крупных MP4-записей.

History and continued editing

История и продолжение редактирования

KADR history is meant to be more than a dump folder. Captures should remain discoverable, sortable and reopenable so saved annotations can be continued later. This area is still being actively refined in the preview build.

История КАДР задумана не как свалка файлов. Снимки должны оставаться доступными, сортируемыми и снова открываться так, чтобы сохранённую разметку можно было продолжить позже. В preview-версии этот раздел ещё активно дорабатывается.

Troubleshooting

Если что-то не работает

Phone screenshot is not appearing on PC

Скриншот с телефона не появляется на ПК

Check that KADR is running on Windows, Companion still shows the intended paired computer, and both devices have network access. If direct transfer cannot reach the PC, leave the item queued rather than deleting the local source immediately.

Проверьте, что КАДР запущен в Windows, Companion всё ещё показывает нужный подключённый компьютер и оба устройства имеют доступ к сети. Если прямая передача не может достучаться до ПК, лучше оставить элемент в очереди, а не удалять исходный файл сразу.

Download stops or says interrupted

Загрузка прерывается

Use the Download page on this site. The buttons are designed to point to the current public release assets. If a release is temporarily being published, try the Releases page to verify which build is current.

Используйте страницу Download на этом сайте. Кнопки должны вести на файлы текущего публичного релиза. Если релиз прямо сейчас публикуется, откройте раздел Обновления и проверьте, какая сборка является актуальной.
